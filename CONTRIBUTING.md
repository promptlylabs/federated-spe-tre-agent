
# Contributions
- Use the **Issues** page for any Bug reports and feature requests.
- All code contributions must pass the pull request checks: the PR title lint (conventional commits, `.github/commitlint.config.mjs`) and the Upwind code scans (SAST, SCA, secrets and IaC).
- Contributions are reviewed by the University of Nottingham Centre for 
Health Informatics and Swansea University Medical School developer team
before they are approved and merged into the codebase.

You can find our Developer Guide here: https://docs.federated-analytics.ac.uk/five_safes_tes/reference_implementation/developer_guide
